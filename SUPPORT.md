# Support

- Installation, PATH, network, local-development, and uninstall behavior: [`docs/install.md`](docs/install.md)
- Catalog scope and entries: [`docs/catalog.md`](docs/catalog.md)
- Local scanning and network boundaries: [`docs/privacy.md`](docs/privacy.md)
- Current scope and known limitations: [`docs/status.md`](docs/status.md)
- Reproducible bug: [open a bug report](https://github.com/travisjneuman/aiup/issues/new?template=bug.yml)
- Catalog or tool candidate: [open a catalog/tool request](https://github.com/travisjneuman/aiup/issues/new?template=catalog-tool.yml)
- Security vulnerability: follow [`SECURITY.md`](SECURITY.md) and do not use a public issue

GitHub Issues are the support and work-intake surface. Discussions, Projects, and the wiki are not used.
