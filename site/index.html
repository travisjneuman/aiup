Install in one minute Star on GitHub

🔍 Scan, don't spray

Default aiup updates whatever it finds. It will not resurrect a tool you removed.

🚫 Never sudo

User-prefix installs. Node CLIs land in ~/.local/share/aiup/npm, not a root-owned global.

🍺 Homebrew, honestly

Child lists are inventory of this Mac, plus a short recommended set — not the entire Homebrew universe.

🔒 Private by default

PATH, app bundles, Homebrew list. No telemetry. No cloud profile.

🎛️ Keys

enter install, expand, or switch to Homebrew
tab check
ctrl+d uninstall
ctrl+o docs
esc leave

⚡ Install

mkdir -p ~/.local/bin
curl -fsSL https://raw.githubusercontent.com/travisjneuman/aiup/main/macos/aiup -o ~/.local/bin/aiup
chmod +x ~/.local/bin/aiup
aiup list
