Get the script, then open the list.

aiup looks at PATH, app bundles, and Homebrew on this machine. It updates what is already there. Missing tools stay missing until you add them.

mkdir -p ~/.local/bin
curl -fsSL https://raw.githubusercontent.com/travisjneuman/aiup/main/macos/aiup -o ~/.local/bin/aiup
chmod +x ~/.local/bin/aiup
export PATH="$HOME/.local/bin:$PATH"
aiup list

bash, python3, curl. fzf for the full-screen list; numbered prompts without it.
