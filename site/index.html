macOS · local-only · MIT

~ aiup

A catalog for the messy pile of coding agents, chat apps, and local-model tools. Scan this Mac. Update what is already installed. Nothing leaves the machine.

GitHub repo Commands

Install

mkdir -p ~/.local/bin
curl -fsSL https://raw.githubusercontent.com/travisjneuman/aiup/main/macos/aiup -o ~/.local/bin/aiup
chmod +x ~/.local/bin/aiup
aiup list

Scan, don’t spray

Default aiup updates whatever it finds. It will not bring back a tool you uninstalled. Use aiup install or aiup only grok to add something on purpose.

Never sudo

User-prefix installs only. Node CLIs land in ~/.local/share/aiup/npm, not a root-owned global. The next update should not die with EACCES.

Honest about Homebrew

Child categories are inventory of this Mac via brew, plus a short recommended list. Zero absent does not mean Homebrew is empty. Apps you installed from a DMG show as on disk, not missing.

Private by default

PATH, app bundles, Homebrew list. No account. No telemetry. Fork and use an AI to extend it if you want — that is optional, not required.

Hermes Desktop and MLX

Hermes Desktop is the official Nous GUI. Same agent as the Hermes CLI. It lives next to Grok Bot and OpenCode desktop — workspaces, not local-model runners.

MLX is Apple’s Apple Silicon engine. mlx-lm chats and serves local models on that engine. Ollama and LM Studio are separate apps; they are not “MLX already installed.”
