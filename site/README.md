# Site

Static files for **https://aiup.neuman.dev**, served by Cloudflare Pages.

Cloudflare Pages project **aiup**:

| Field | Value |
|---|---|
| Production branch | `main` |
| Root directory | `site` |
| Build command | empty |
| Build output | empty |
| Build watch paths | `site` only (drop `*` so README-only commits do not deploy) |
| Variables / bindings | none |

`catalog.json` is generated by `scripts/sync-public-docs` from `macos/aiup`.
